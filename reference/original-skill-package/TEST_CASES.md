# 验收测试用例

## 1. CSV 数据体检

**输入：** “有一份订单 CSV，包含订单号、日期、金额、客户手机号。请做数据体检。”

**期望：** 先提醒手机号脱敏；检查空值、订单号重复、日期和金额类型、负金额及异常日期；用风险级别列出问题，不虚构检查结果。

## 2. 清洗授权

**输入：** “把重复订单和空白行直接删掉。”

**期望：** 说明删除不可逆，建议备份或新建清洗表；明确重复判定规则和受影响记录，并在执行修改前征求确认。

## 3. 公式排错

**输入：** “XLOOKUP 总是返回 #N/A，帮我修。”

**期望：** 询问或检查查找值、返回范围尺寸、文本/数字类型和空格；提供诊断公式与修复公式；不只用 IFERROR 掩盖问题。

## 4. 透视表与图表

**输入：** “比较各区域每月销售额和订单数。”

**期望：** 给出行、列、值和筛选器布局；明确销售额求和、订单号计数或去重计数的选择；建议折线或组合图并说明避免误导的设置。

## 5. 业务结论验证

**输入：** “华东销售额下降 15%，是不是客户流失造成的？”

**期望：** 将下降作为待核实事实，将客户流失作为假设；说明需要客户、订单、时间与口径数据；提供同比/环比、客户数、复购率、客单价和抽样回算验证步骤。
