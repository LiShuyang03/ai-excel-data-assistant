# AI Excel 数据分析助手

面向 Excel 和 CSV 的实用分析技能包。它帮助用户从数据体检开始，形成可执行的清洗建议、可靠公式、透视表和图表设计、业务解读与验证步骤。

## 适用任务

- 检查缺失、重复、格式混乱、异常值和口径不一致；
- 设计不破坏原数据的清洗方案；
- 编写、解释和排查 Excel 公式；
- 规划透视表、指标和图表；
- 解读销售、运营、财务、人力或客户数据；
- 对计算结果进行回算、抽样和边界验证。

## 使用示例

“请检查这份销售 CSV 是否适合按月分析，列出数据质量问题，并在不修改原文件的前提下给出清洗步骤。”

“订单表中金额被识别为文本，怎样转换并检查是否存在重复订单？请给出 Excel 公式和验证方法。”

“我想看各区域本季度销售额和毛利率，请设计透视表字段布局、图表和结论验证清单。”

## 使用边界

请在上传前删除或脱敏敏感信息。助手不会编造数据或结论；涉及覆盖、删除、合并、填充等原始数据修改时，会先请求确认。
